## 1 概述

底盘控制固件，运行于大疆 C 型开发板（STM32F407IGH6，168 MHz）。

驱动对象：

| 对象 | 数量 | 接口 |
|---|---|---|
| 全向驱动轮 M3508 | 4 | CAN1 |
| 俯仰步进（TB6600 + 两相步进） | 1 | TIM1 PWM |
| 无刷（BLHeli_S 电调） | 3 | TIM8 + DMA，DShot300 |
| 蓝牙遥控模块（塔克 SBTCOM1） | 1 | USART1 |
| K210 视觉 | 1 | USART6 |

固件尺寸约 20.8 KB（Code），ZI 2.7 KB。

### 运行模式

| 模式 | 数据来源 | 输出 |
|---|---|---|
| RC | USART1 蓝牙摇杆 | vx / vy / w 直接映射摇杆 |
| FOLLOW | USART6 K210 目标偏角 | 仅输出转向 w；vx = vy = 0 |

模式切换：蓝牙手柄 **B 键**（`key2` 的 bit1）按下瞬间切换，切换时清四轮 PID 积分。

FOLLOW 模式的距离保持环由 `K210_FOLLOW_VX_ENABLE` 控制，当前为 `0`（关闭）。

## 2 硬件拓扑

```
C 型开发板 (STM32F407IGH6, 168 MHz)
│
├── CAN1  PD0/PD1  1 Mbps ──────► M3508 驱动轮 ×4
│                                 ├ 0x201 拨码1 右后 RB
│                                 ├ 0x202 拨码2 左后 LB
│                                 ├ 0x203 拨码3 左前 LF
│                                 └ 0x204 拨码4 右前 RF
│
├── CAN2  PB5/PB6  1 Mbps ──────► 未使用
│
├── USART1  PA9(TX)/PB7(RX)  115200 ──► 塔克蓝牙模块 SBTCOM1
│
├── USART6  PG14(TX)/PG9(RX)  115200 ─┬─► K210 视觉
│                                      └─► 调试打印（同一引脚）
│
├── TIM1  PE9(STEP) / PE11(DIR) / PE13(限位) ──► TB6600 + 两相步进
│
├── TIM8 + DMA2  PC6(CH1) / PI6(CH2) / PI7(CH3) ──► BLHeli_S 电调 ×3
│
└── GPIO  PH10(蓝) / PH11(绿) / PH12(红) ──► 板载三色 LED
```

`USART6` 的 TX（PG14）被 K210 通信和调试打印共用，详见 3.3。

## 3 接线映射

### 3.1 电源与共地

| 项目 | 取值 | 说明 |
|---|---|---|
| C 板供电 | 24 V | 经分电板输入，板上 DC-DC 产生 5 V / 3.3 V |
| 逻辑电平 | 3.3 V | 串口、DShot、步进信号均为 3.3 V |
| 步进驱动器 | 12~24 V | TB6600 独立供电，与 C 板仅共地 |
| 电调 | 电池直供 | 动力电取自分电板，信号线仅走 DShot |

所有外设必须与 C 板共地。不共地时信号无参考电平，表现为间歇性收发失败或信号跳变。

### 3.2 CAN 总线

两路均为 1 Mbps：`Prescaler = 3`，`TimeSeg1 = 9TQ`，`TimeSeg2 = 4TQ`，APB1 42 MHz ÷ 42 = 1 MHz。

| 总线 | 引脚 | 速率 | 挂载设备 |
|---|---|---|---|
| CAN1 | `PD0` / `PD1` | 1 Mbps | M3508 ×4（AF9） |
| CAN2 | `PB5` / `PB6` | 1 Mbps | 无（AF9） |

#### 电机编号

对应关系由电机驱动器拨码决定。

| 数组下标 | CAN ID | 拨码 | 轮位 | 位置 |
|---|---|---|---|---|
| 0 | `0x201` | 1 | RB | 右后 |
| 1 | `0x202` | 2 | LB | 左后 |
| 2 | `0x203` | 3 | LF | 左前 |
| 3 | `0x204` | 4 | RF | 右前 |

#### 轮向修正

`user/chassis_solve.h`：

```c
#define WHEEL_DIR_RB  (+1)
#define WHEEL_DIR_LB  (+1)
#define WHEEL_DIR_LF  (+1)
#define WHEEL_DIR_RF  (+1)
```

某轮转向相反时改对应宏为 `-1`。逆解公式基于轮轴几何关系，不改动。

### 3.3 串口

均为 115200 8N1。

| 外设 | 引脚 | 连接 |
|---|---|---|
| USART1 | `PA9` TX / `PB7` RX | 塔克 XTARK SBTCOM1 蓝牙模块（4-pin） |
| USART6 | `PG14` TX / `PG9` RX | K210 视觉，同时用于调试打印 |

#### USART6 引脚复用

`debug_port_init()` 与 `k210_follow_init()` 均使用 USART6，两个模块都向 PG14 发送数据。

因此 **K210 会接收到固件全部调试输出**（启动信息、蓝牙帧统计、模式切换提示）。K210 侧解析需按前缀 `K210,` / `BOT,` 过滤，非合法行直接丢弃。

PG9（K210 → C 板）不受影响。

#### K210 上行帧

```
K210,seq,state,id,err_deg,dist_m*hh\n
```

| 字段 | 说明 |
|---|---|
| `seq` | 帧序号 |
| `state` | `L` 锁定 · `S` 画面无人 · `X` 视觉不可用 |
| `id` | 目标 ID |
| `err_deg` | 水平偏角，正 = 目标在画面右侧 |
| `dist_m` | 距离（米），`-1` = 未知；当前固件不使用 |
| `*hh` | XOR 校验 |

发送频率约 8 Hz。底盘侧看门狗 500 ms，超时后转向输出归零。

#### 底盘下行帧

```
BOT,<mode>,<state>,<err_deg>,<w>\n
```

周期 200 ms。

#### 蓝牙帧

| 帧号 | 来源 | 结构 |
|---|---|---|
| `0x20` | 手机 APP | `AA 55 0C 20 TY LX LY RX RY 键1 键2 SUM` |
| `0x90` | 微信小程序 | `AA 55 09 90 01 摇X 摇Y 键1 SUM` |
| `0xA0` | 蓝牙手柄 | `AA 55 0F A0 01 LX LY RX RY 键1 键2 键3 右扳机 左扳机 SUM` |

摇杆值范围 -127 ~ +127，中位 0。

#### 按键字节定义

蓝牙手柄（`0xA0`）帧：

- `key1` 为方向枚举，非位掩码：`1` 上 / `3` 右 / `5` 下 / `7` 左
- `key2` 为位掩码：bit0 = A、bit6 = LB、bit7 = RB

`bt_rc.h` 中另有 APP/小程序帧的 `key1` 位定义（`BT_KEY_R2` ~ `BT_KEY_A`），与手柄帧的方向枚举不同源。

### 3.4 步进（俯仰轴）

| 信号 | 引脚 | 配置 | 驱动器端子 |
|---|---|---|---|
| STEP | `PE9` | TIM1_CH1 PWM | PUL+（PUL- 接 GND） |
| DIR | `PE11` | 推挽输出 | DIR+（DIR- 接 GND） |
| 限位 | `PE13` | 输入上拉 | 开关一端接 PE13，另一端接 GND |

#### 限位开关

开关常开、对 GND，安装在行程下端（零位）。PE13 内部上拉，未压住时读高，压住时读低，故 `STEP_LIMIT_ACTIVE_LEVEL = 0`，`STEP_LIMIT_AT_UP = 0`。

行为：

- 压住时停止，并禁止继续下降
- 上升方向不受限制
- 离开限位持续 200 ms 后解锁
- 压住时 `stepper_get_pos()` 清零

#### 细分与脉冲数

TB6600 当前为 8 细分，`STEP_STEPS_PER_REV = 200 × 8 = 1600`。

| 驱动器细分 | `STEP_STEPS_PER_REV` |
|---|---|
| 8 | 1600 |
| 16 | 3200 |
| 32 | 6400 |

修改驱动器细分拨码后，必须同步修改该宏，否则转速与位置计算全部失准。

### 3.5 无刷（DShot300）

| 通道 | 引脚 | 定时器 |
|---|---|---|
| CH1 | `PC6` | TIM8_CH1 |
| CH2 | `PI6` | TIM8_CH2 |
| CH3 | `PI7` | TIM8_CH3 |

三路共用 DMA2_Stream1 / Channel 7。TIM8 每个 update 事件搬运 4 个字至 CCR1~CCR4（CH4 未用）。DMA 缓冲布局 `[槽][CH1, CH2, CH3, CH4]`，共 50 槽 × 4 = 200 字。

#### 帧格式

```
16 bit / 300 kbps
[ 11 bit 值 ][ 1 bit 遥测请求 ][ 4 bit CRC ]

值 0        停车
值 1~47     特殊命令
值 48~2047  油门（仅正转）
```

标准 DShot 无反向油门区间。修改电机转向使用 BLHeliSuite：连接电调后 `Motor Direction` 设为 `Reversed`，`Write Setup` 写入，断电保持。

#### 操作

| 按键 | 功能 |
|---|---|
| A 键（`key2` bit0） | 按住出力，松开停止 |
| RB（`key2` bit7） | 加速，每 50 ms 变化 2.5% |
| LB（`key2` bit6） | 减速，每 50 ms 变化 2.5% |

上电后保持零油门 2000 ms（`DSHOT_ARM_MS`），期间持续发送合法帧以完成电调解锁。

### 3.6 LED

| 颜色 | 引脚 | 备注 |
|---|---|---|
| 蓝 B | `PH10` | 共阳，低电平点亮 |
| 绿 G | `PH11` | 共阳，低电平点亮 |
| 红 R | `PH12` | 共阳，低电平点亮 |

#### 状态指示

| 模式 | 现象 | 含义 |
|---|---|---|
| RC | 绿灯常亮 | 蓝牙在线 |
| RC | 绿灯 1 Hz 慢闪 | 蓝牙离线 |
| RC | 蓝灯常亮 | 曾收到有效帧 |
| RC | 红灯 5 Hz 快闪 | 校验失败计数增长 |
| FOLLOW | 蓝灯常亮 | 已锁定目标（`state = L`） |
| FOLLOW | 红灯 1 Hz 慢闪 | K210 在线，画面无人（`S`/`X`） |
| FOLLOW | 红灯 5 Hz 快闪 | K210 离线 |

## 4 上电流程

初始化顺序：

```
MX_GPIO_Init
MX_CAN1_Init / MX_CAN2_Init
MX_USART1_UART_Init / MX_USART6_UART_Init
MX_IWDG_Init
MX_TIM1_Init / MX_TIM8_Init        ← 由 CubeMX 生成代码调用

can_filter_init
bt_rc_init                        蓝牙，USART1
debug_port_init                   调试，USART6
led_ind_init
stepper_init                      DIR + 限位 + PWM 通道
DShot_Init                        环形 DMA，立即开始发送零油门帧
等待 2000 ms 电调解锁（期间刷新 IWDG）
k210_follow_init                  K210，USART6
进入主循环
```

主循环周期 10 ms，每拍执行：

1. 读取遥控 / K210 数据，判断模式
2. 全向轮逆解，得到四轮目标转速
3. 四轮 PID 计算，发送 CAN 电流指令
4. 步进方向与限位判断
5. 无刷油门斜坡与 DShot 输出
6. LED 指示、刷新 SWD 监控块、刷新 IWDG

IWDG 全程开启。主循环阻塞超过超时时间将触发复位。

## 7 故障排查

排查顺序：接线 → 配置 → 代码。

### 底盘不动作

| 现象 | 检查项 |
|---|---|
| 四轮全不动 | CAN1 的 H/L 是否接反；120 Ω 终端电阻；是否处于 RC 模式且蓝牙在线 |
| 单轮不动 | 该电机驱动器拨码是否与表中位置一致；CAN 线是否串接到位 |
| 方向错误 | `WHEEL_DIR_xx` 宏；确认电机未装反 |
| 转动抖动 | PID 参数；用 `_swd_mon_v2.py` 查看 CAN 反馈转速是否正常 |

### 步进异常

| 现象 | 检查项 |
|---|---|
| 完全不转 | 限位线（PE13）是否断线或被压住；TB6600 的 ENA 电平；驱动器供电 |
| 只能上升不能下降 | 限位被判定压住；开关是否卡滞；`STEP_LIMIT_AT_UP` 是否正确 |
| 实际转速远低于设定 | 驱动器细分拨码与 `STEP_STEPS_PER_REV` 不匹配 |
| 啸叫 | 步进电机固有现象，频率随步频变化 |

### 无刷异常

| 现象 | 检查项 |
|---|---|
| 上电无反应 | 电调动力电；DShot 信号线是否接在 PC6/PI6/PI7 |
| 单路间歇性抖动或停转 | 检查该路信号线；确认 `dshot_apply()` 中 `PAR` / `M0AR` / `NDTR` 三者同时复位 |
| 出现重新初始化提示音 | 该路信号被判丢失，检查线路与焊点 |
| 转向相反 | 通过 BLHeliSuite 修改 `Motor Direction` |

### K210 跟随异常

| 现象 | 检查项 |
|---|---|
| 红灯 5 Hz 快闪 | K210 未上电或未运行；TX 线是否接在 PG9 |
| 红灯 1 Hz 慢闪 | 通信正常，K210 上报 `S` 或 `X`，视觉未锁定目标 |
| 转向相反 | `K210_FOLLOW_DIR` 改为 `-1` |
| 原地左右摆动 | 增大 `K210_DEADBAND_DEG` 或减小 `K210_FOLLOW_KP` |
| K210 收到乱码 | 调试打印与 K210 共用 PG14，属正常现象，K210 侧需按前缀过滤 |

### 蓝牙遥控异常

| 现象 | 检查项 |
|---|---|
| 绿灯慢闪 | 模块未上电；主机未连接；TX/RX 是否接反 |
| 红灯快闪 | 收到数据但校验失败；波特率非 115200 |
| 能接收但无控制效果 | `key1` / `key2` 是否用错（见 3.3） |

### 运行中自行复位

IWDG 超时。检查主循环内是否存在阻塞调用，以及是否遗漏 IWDG 刷新。

## 8 维护守则

### 安全

- 调试无刷、电调、信号线之前断开桨叶
- 首次通电或修改方向、增益后，上电时扶住机构
- 不在带电状态下插拔电机线（CAN 与电调动力线均同）

### CubeMX 重新生成代码

- `MDK-ARM/ctrl_2005.uvoptx` 必须存在且非空。缺失时报找不到文件；0 字节时生成崩溃，日志仅显示 `Problem in the update / KO`
- `.mxproject` 需保留在版本库中
- USER CODE 3 区块必须包含 `while(1)` 的收尾 `}`，否则 `main()` 缺少右括号
- 不在 USER CODE 2 中调用 `MX_TIM1_Init` / `MX_TIM8_Init`，生成代码已包含
- 自定义中断逻辑写入生成函数的 `USER CODE BEGIN xxx_IRQn 0` 槽位，不定义同名中断函数
- ioc 中需显式声明 `GPIOParameters=GPIO_Speed,GPIO_PuPd`，否则生成结果为 LOW / NOPULL

### 版本管理

- `git status` 中 `Drivers/` 下的大量修改通常为行尾差异，用 `git diff --name-only` 确认真实改动后决定是否提交
- 每轮改动单独提交，提交信息包含：改了什么、为什么改、验证程度、遗留问题
- 引脚或参数变更后同步更新本文档

### 改动后的验证顺序

1. 编译，确认 `0 Error(s), 0 Warning(s)`
2. 车架空，先只接 CAN 与电源，确认四轮按指令转且方向正确
3. 再接步进，手动压限位确认能停、能反向
4. 最后接无刷，拆桨通电，确认三路都能解锁起转
