# 底盘跟随串口协议（K210 → 下位机）

版本 v1.0（2026-10-23）。K210 端实现见 `follow_link.py`（发/收）+ `body_detect.py`
（配置块"底盘跟随链路"）；PC 端验证工具见 `tools/follow_host.py`。

## 1. 物理层

| 项 | 值 |
|---|---|
| 接口 | K210 **板载扩展口**（丝印 **TXD=IO8**、**RXD=IO6**，Yahboom 官方引脚表） |
| 电平 | 3.3V TTL（K210 与 RoboMaster C 板串口均为 3.3V TTL，可直连） |
| 波特率 | 115200，8N1 |
| 接线 | K210 IO8(TXD) → 下位机 RX；K210 IO6(RXD) ← 下位机 TX；**两板必须共地** |

不能用的引脚：IO4/5（USB 串口）、IO13/14（WiFi 模块，带跳线帽）、IO17（BOOT 键）。

**单板自检**：不用接下位机，拿一根杜邦线把扩展口 TXD(IO8) 和 RXD(IO6) 短接，
K210 发的帧会被自己收回来，`[CHAS]` 行立刻出现 → 证明电气链路通。

## 2. 帧格式（K210 → 下位机，单向为主）

```
K210,<seq>,<state>,<id>,<err_deg>,<dist_m>*<hh>\n
```

- 每帧一行，`\n` 结尾，ASCII 文本，长度 < 40 字节，约 **8Hz**（`FOLLOW_PERIOD_MS=120`）
- `<hh>` = 星号前所有字符的**异或校验**，两位小写 hex
- 例：`K210,123,L,3,4.2,2.15*2b`

| 字段 | 含义 |
|---|---|
| `seq` | 帧序号，0~65535 循环。**收端可用来查丢帧** |
| `state` | `L`=已锁定人在跟踪；`S`=画面里没人；`X`=视觉不可用（模型没加载） |
| `id` | 锁定目标的跟踪 id；无目标为 0 |
| `err_deg` | 人相对画面中心的**水平偏角**，单位度，1 位小数。**正 = 人在画面右侧 → 底盘应右转（顺时针）；负 = 左转。人居中为 0.0** |
| `dist_m` | HEIGHT 法估距（米，2 位小数）；未知为 `-1`。转向控制可忽略此字段 |

角度换算：`err_deg = atan(err_px / fx)`，`fx = 410.6`（棋盘格标定）。
画面 320 宽，边缘 ±160px ≈ **±21.4°** 全量程。

## 3. 下位机建议行为

1. **`L`**：按 `err_deg` 做闭环转向（P 控制即可，建议 `Kp≈2`，输出限幅），
   死区 ±0.8°；`dist_m` 字段本期可忽略（不做进退）
2. **`S`**：停止转向（保持当前朝向），不要自旋找
3. **`X`**：停止，等视觉恢复
4. **看门狗**：超过 **500ms** 没收到任何帧（约 4 帧没来）→ 视为 K210 挂了，停止
5. 用 `seq` 监控丢帧率，串口正常时跳帧数应恒为 1

## 4. 下位机 → K210 方向

K210 **已经在收**（非阻塞，IO6）。收到任何完整行会以 `[CHAS] <内容>` 限速回显到
USB 调试串口。格式不约定——你那边发什么 K210 就原样显示什么，用于确认
"通信接通了会看到 RoboMaster 的信息"。

## 5. K210 端配置（body_detect.py 配置区）

```python
FOLLOW_ENABLE    = True    # 总开关
FOLLOW_UART_ID   = 2       # UART 外设号
FOLLOW_TX_IO     = 8       # 扩展口丝印 TXD
FOLLOW_RX_IO     = 6       # 扩展口丝印 RXD
FOLLOW_BAUD      = 115200
FOLLOW_PERIOD_MS = 120     # 发帧周期
FOLLOW_LOST_FRAMES = 5     # 连续丢 N 帧才放弃锁定 id
FOLLOW_MIRROR_REPL = True  # 每帧镜像到 USB 串口 [FOL>]（上线可关）
CAM_FX = 410.6             # 横向焦距
```

## 6. 锁定逻辑（K210 侧，下位机不用管）

- 上一帧锁的人还在 → 继续锁（不换目标）
- 锁的人消失但画面里还有别人 → 立即改锁**最接近画面中心**的人
- 画面里没人 → 发 `S`；连续 `FOLLOW_LOST_FRAMES`(5) 帧没人 → 放弃 id，
  下次见人就重新按"最居中"选
- 模型没加载（预览模式）→ 发 `X`，底盘停

## 7. 验证清单（按顺序做）

1. **PC 单测**（已过）：`python tools/_test_follow_link.py` → ALL PASS
2. **板端发帧**：部署后看 USB 串口，应每 120ms 一行 `[FOL>] K210,…`，
   无人时 `S`、有人在时 `L` 且 `err_deg` 随人移动变化、屏幕左下角有 `FOL:` 角标
3. **环回自检**：杜邦线短接 IO8↔IO6 → 出现 `[CHAS] K210,…` 且 follow_host
   解析正常（需要 USB-UART 小板，或直接看 `[CHAS]` 回显）
4. **接底盘**：`python tools/follow_host.py COM16` 监听 USB 口看 `[FOL>]`，
   底盘侧则收硬件 UART；K210 端出现 `[CHAS]` 即"看到了 RoboMaster 的信息"
